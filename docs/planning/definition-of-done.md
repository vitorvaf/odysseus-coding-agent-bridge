# Definition of Done

> **Status:** Proposed

Define quando uma fatia, tarefa ou marco é considerado concluído.

## Critérios gerais

* [ ] Implementação completa conforme spec.
* [ ] Código revisado.
* [ ] Testes unitários passando.
* [ ] Testes de contrato passando.
* [ ] Testes de integração passando (quando aplicável).
* [ ] Documentação atualizada.
* [ ] Backlog atualizado.
* [ ] Risk register revisado (se aplicável).
* [ ] ADR registrado (se houver mudança de premissa).

## Específico para slices verticais

* [ ] Fluxo ponta a ponta demonstrável.
* [ ] Relatório final conforme contrato.
* [ ] Logs e métricas emitidos.
* [ ] Artefatos persistidos e referenciados.
* [ ] `run_create` idempotente.

## Específico para hardening

* [ ] Testes de segurança passando.
* [ ] Threat model revisado.
* [ ] Política atualizada.

## Específico para documentação

* [ ] Texto revisado.
* [ ] Links relativos válidos.
* [ ] Diagramas Mermaid renderizam.
* [ ] Sem afirmações não verificadas.
* [ ] Marcadores de status aplicados.

## Específico para release

* [ ] Versionamento aplicado.
* [ ] Backup pré-release.
* [ ] Plano de rollback.
* [ ] Sign-off do patrocinador.
* [ ] Notas de release.
